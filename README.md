Aim
To write a Python program to create and perform various operations on a dictionary, use dictionary methods, and find the frequency of each character in a string.

Algorithm
Start the program.
Create a dictionary student with name, age, department, and employee ID.
Display the dictionary.
Add marks to the dictionary and display it.
Update the student's age and display the dictionary.
Delete the department key and display the dictionary.
Display the dictionary's keys, values, and items.
Use get() to access the student's name and marks.
Use update() to update the age and marks.
Take a string as input from the user.
Create an empty dictionary called frequency.
Traverse each character in the string.
If the character already exists, increase its count by 1; otherwise, set its count to 1.
Display the frequency of each character.
Stop the program.
